What's new

Latest updates.

  • v3 — Security & reliability audit

    NEW
    • Full code audit: every backend function and frontend script was reviewed file-by-file for bugs, cross-file wiring and security gaps.
    • Provider timeouts: all AI provider calls now abort after 25s if a provider hangs, so a stalled upstream can no longer freeze the API.
    • Gemini key safety: the Gemini key moved from the URL into the x-goog-api-key header — it can no longer leak into logs or proxies.
    • Provider compatibility: providers that reject stream_options are retried once without it; error messages now include the provider's actual error text.
    • Free quota consistency: /api/free-quota now reads the same shared limits as the free router — changing the free quota can never silently break it again.
    • Security verified: admin endpoints, wallet reservations, video/image jobs, MCP proxy (SSRF-guarded), BYOK redaction, per-user rate limits and Firestore rules all re-checked — no way found to spend another user's credits or steal API keys.

  • v2.1 — Stability & polish release

    2026
    • Backend fixed: added the missing package.json so Netlify can build the API functions again — payments, wallet, free chat and video generation all depend on it.
    • Free chat fixed: the /api/chat wrapper had a require bug that killed the free tier; now calls the handler correctly.
    • Payment history added: the Wallet History tab was empty — it now shows your top-up requests (with status) and full credits ledger.
    • Reject flow fixed: admins must now enter a reason when rejecting a payment, which the server always required.
    • New models: Mistral Large / Small / Magistral (Vibe AI) and Meta Llama 4 Scout & Maverick (free via OpenRouter).
    • Pricing page: a real Pricing page now exists for all plan links.
    • Design polish: composer focus glow, refined chat bubbles, button hover lift, modal blur, smoother scrollbars.

  • Memory, completed

    Auto-learn with accept/reject, per-project memory, chat recall and an automatic codebase map.

  • Version history & Undo

    Snapshots before every agent edit, timeline with diff view, restore and one-click undo (last 30 kept).

  • MCP support

    Add MCP servers (GitHub, Notion, Slack, Linear presets), proxied calls, tool-use loop with approve/deny cards.

  • Team mode & scheduled agents

    Planner, Coder and Reviewer with per-role models. Agents on a schedule or webhook with run logs and notifications.

  • Quality tools

    Auto test & auto-fix in a sandboxed preview, a six-template gallery, and wallet-metered AI image generation with alt text.

  • Video Studio

    Video scripts with shot lists and captions, hero/background/testimonial video sections, metered video generation with a daily cap, in-browser text overlays.

  • Growth features

    Deep research with cited sources and downloadable reports, a browser agent, public share links, usage dashboard, Vercel deploys, referral credits and a public prompt library.

  • Animation Pack

    Animation intensity and effect presets added to Settings. The agent applies them to everything it builds.

  • Memory Manager

    Layered memory with pin, delete, export, project memory and a token counter.

  • Welcome workspace

    New and logged-in workspaces now start with a single index.html showing "Welcome SAIM AI AGENT".

  • Agent Power and Memory

    Work modes and persistent memory added. Saved to Firestore.

  • New model picker

    Choose an AI, then its model. Your own key and paid credits both work.

  • Grok, Kimi and Qwen

    Added with their own endpoints.

  • In-app input dialogs

    New file names are now asked in an in-app dialog.

  • API key saving fixed

    Firestore rules did not allow users to write their own settings. Keys now save.

  • Separate pages

    Features, Models, Pricing, How to use and What's new are now separate pages.
