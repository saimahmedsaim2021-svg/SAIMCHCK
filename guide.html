How to use

From first login to publishing in 13 steps.

  1. 1. Create an account

    Press Login / Sign Up. A free account includes 50,000 tokens.

  2. 2. Choose an AI and model

    Click the model button above the chat. Pick an AI first (for example Claude), then one of its models.

  3. 3. Add your own API key (optional)

    In the model menu choose "Add your own API key" and paste it. It is saved to your account and works on every device.

  4. 4. Or buy paid credits

    No key? Open "Paid credits", choose a pack and pay. Credits are added to your wallet.

  5. 5. Describe your project

    Type or speak what you want to build. Press Autopilot and the agent plans and writes every file.

  6. 6. Turn on Agent Power

    Open Settings and enable Plan first, Self-review or Autonomous. Write your project details in Agent Memory.

  7. 7. Manage files

    Press New file and enter a name such as style.css. Edit in the editor and check the preview.

  8. 8. Publish

    Push to GitHub or deploy to Netlify. Work with a teammate in a Live sync room.

  9. 9. Version history

    Open Tools → Versions+ to see every agent edit, view diffs, restore a version or undo the last change.

  10. 10. Connect MCP tools

    Tools → MCP Tools: add a preset (GitHub, Notion, Slack, Linear) or your own server, press List tools, then ask the agent to use them. Approve or deny each call in the chat.

  11. 11. Team mode & schedules

    Tools → Team Mode runs Planner, Coder and Reviewer on one task. Tools → Schedule runs an agent every few hours, daily, or from a webhook.

  12. 12. Test, templates, images & video

    Tools → Auto Test checks your app in a sandbox and fixes errors. Templates starts from a ready design. AI Image and Video generate media with paid credits.

  13. 13. Share & grow

    Tools → Growth: deep research with cited sources, public read-only share links, your usage dashboard, Vercel deploys, referral credits and the prompt library.
